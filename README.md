# Urban Company mobile app preview

A mobile-first React preview based only on the **Urban combanyscreen shots** and **Urban combanydesign system** sections in the supplied Figma file.

It includes the home screen, AC category, diagnosis banner, UC Cover panel, service shortcuts, 2–5 AC Foam-jet packages, AC repair and gas refill, installation and uninstallation, service details, cart, professional selection, time selection, and payment summary.

Images and visible service details, prices, timings, and ratings are copied from the supplied screenshots. They are reference values, not live availability. Unknown prices and fees stay pending; payment is not connected.

Run with `npm install` and `npm run dev`.
## Start on Windows

Double-click `start-local-preview.bat`. It opens the app at `http://localhost:5173/` and keeps the server window open. Close that window when you are done.

If Windows says `npm` is missing, install Node.js first.
