# Vaayu demo conversations (all six languages)

Legend
- [VOICE ONLY] the screen shows nothing but a calm voice circle.
- [SCREEN] the interactive room appears or changes (tool calls: reveal_interface, update_visual_scene).
- [CTA] the "See my diagnosis" button appears after the short suspense animation (tool call: show_recommendation).
- The greeting is the same for every call, then the user picks a language.
- Scripts are written for the voice, so there are no emojis and the pauses come from commas, dashes and "...".
- IMPORTANT: have a native speaker review the Telugu, Tamil, Malayalam and Kannada lines before launch, especially the jokes.

Greeting, spoken first on every call [VOICE ONLY]
Vaayu: Namaste! Hello! Vanakkam! I am Vaayu from Urban Company. Which language are you comfortable in... English, Hindi, Telugu, Tamil, Malayalam or Kannada?
